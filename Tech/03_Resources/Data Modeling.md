# 🧱 Data Modeling

## 📖 Definisi
> Proses mendesain **struktur data** dan hubungan antar entitas — dari abstract (conceptual) → logical → physical schema. Fondasi dari database yang scalable dan mudah dipertanyakan.

## 🔑 Poin Inti
- **Conceptual** — entitas & relasi bisnis ([[ER Diagram]]).
- **Logical** — atribut, key, cardinality, tanpa spesifik DBMS.
- **Physical** — kolom, tipe data, indeks pada engine tertentu.
- Modeling untuk OLTP ([[Normalization]]) berbeda dari OLAP ([[Data Warehouse]] — star/snowflake schema).
