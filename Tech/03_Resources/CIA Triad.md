# 🎯 CIA Triad

## 📖 Definisi
> Tiga pilar fundamental information security: **Confidentiality** (kerahasiaan), **Integrity** (keutuhan), **Availability** (ketersediaan).

## 🔑 Poin Inti
- **Confidentiality** — data hanya diakses pihak berwenang. Mekanisme: enkripsi, [[Authentication]], access control.
- **Integrity** — data tidak diubah tanpa izin. Mekanisme: [[Hashing]], [[Digital Signature]], audit log.
- **Availability** — sistem tersedia saat dibutuhkan. Mekanisme: redundancy, backup, DDoS mitigation.
- Setiap kontrol keamanan sebaiknya dievaluasi terhadap tiga dimensi ini.
