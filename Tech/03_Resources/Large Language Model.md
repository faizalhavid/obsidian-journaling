# 🧠 Large Language Model (LLM)

## 📖 Definisi
> **LLM** adalah model neural network berskala besar (miliaran parameter) yang dilatih pada korpus teks masif untuk memprediksi token berikutnya, sehingga mampu memahami dan menghasilkan bahasa alami.

## 🔑 Poin Inti
- **Arsitektur**: umumnya berbasis [[Transformer Architecture]] dengan mekanisme self-attention.
- **Training**: pretraining (self-supervised) → fine-tuning → RLHF.
- **Emergent capability**: reasoning, coding, translation muncul dari skala.
- **Context Window**: batas token input+output yang bisa diproses dalam satu inferensi.

## 💡 Contoh Model
- Claude (Anthropic), GPT-4 (OpenAI), Gemini (Google), Llama (Meta).
