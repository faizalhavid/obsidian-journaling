# 🕸️ OWASP Top 10

## 📖 Definisi
> Daftar berkala **10 risiko web application security terkritis** yang dirilis oleh OWASP Foundation. Rujukan wajib untuk [[Secure Coding]] dan pentest scoping.

## 🔑 Kategori (edisi 2021, masih dominan 2026)
1. **A01 Broken Access Control**
2. **A02 Cryptographic Failures**
3. **A03 Injection** — termasuk [[SQL Injection]], [[XSS]]
4. **A04 Insecure Design**
5. **A05 Security Misconfiguration**
6. **A06 Vulnerable Components**
7. **A07 Identification & Auth Failures**
8. **A08 Software & Data Integrity Failures**
9. **A09 Security Logging & Monitoring Failures**
10. **A10 SSRF**
