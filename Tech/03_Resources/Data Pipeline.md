# 🌊 Data Pipeline

## 📖 Definisi
> Rangkaian langkah otomatis yang **memindahkan dan mentransformasi data** dari satu atau banyak sumber menuju destinasi (analytics warehouse, ML feature store, dashboard).

## 🔑 Poin Inti
- Bentuk umum: [[ETL]], [[ELT]], streaming ([[Apache Kafka]] + [[Apache Spark]]).
- Kualitas pipeline diukur dari: **reliability, latency, throughput, cost, observability**.
- Butuh [[Data Quality]] checks di titik-titik kritis.
- Diorkestrasi via [[Airflow]] / Prefect / Dagster.
