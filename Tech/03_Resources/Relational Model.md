# 🧮 Relational Model

## 📖 Definisi
> Model data yang mengorganisir informasi ke dalam **tabel (relasi)** dengan baris (tuple) dan kolom (atribut), dengan relasi antar-tabel didefinisikan melalui **primary key** dan **foreign key**.

## 🔑 Poin Inti
- Diperkenalkan oleh E. F. Codd (1970).
- Menjamin konsistensi via [[ACID]] transactions.
- Query menggunakan [[SQL]].
- Contoh RDBMS: [[PostgreSQL]], [[MySQL]], SQLite, Oracle.
- [[Normalization]] mengurangi redundansi; [[Denormalization]] mengorbankan itu demi kinerja.
