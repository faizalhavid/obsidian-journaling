# 🚀 Folder: Projects

## 📖 Tentang Folder
> Folder ini menyimpan **project notes** yang goal-driven: setiap note punya tujuan jelas, deadline, dan progress tracking. Gunakan untuk proyek aktif yang sedang dikerjakan — bukan evergreen concept.

Setiap note di folder ini harus menggunakan `Template - Project.md` dan memiliki `tags: [project]` di frontmatter.

Kalau proyek selesai, arsipkan ke `03_Resources/` (kalau menghasilkan knowledge) atau hapus kalau tidak relevan lagi.
