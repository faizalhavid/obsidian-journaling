> Folder ini menyimpan **research notes**: investigasi mendalam, literature review, dan eksplorasi topik yang belum cukup matang untuk jadi atomic concept note di `03_Resources/`. Gunakan sebagai *staging area* sebelum dipecah jadi evergreen notes.
