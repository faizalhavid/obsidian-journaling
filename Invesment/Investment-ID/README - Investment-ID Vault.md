## 🔄 Alur Kerja Standard

```
INBOX (ide) → PROJECT (riset) → EMITEN NOTES (analysis)
    ↓
FUNDAMENTAL + TECHNICAL + VALUASI
    ↓
THESIS (investment decision framework)
    ↓
DECISION JOURNAL (reasoning tertulis)
    ↓
TRADE LOG (eksekusi)
    ↓
MONITORING (ongoing watch)
```

Setiap tahap ada template di `99_Templates/`.

## ⚠️ Prinsip Kerja

1. **Never invent data.** Semua angka harus dari sumber terverifikasi (IDX, Yahoo Finance, Stockbit, annual report). Placeholder `{{isi setelah cek laporan keuangan}}` sampai data real diisi.
2. **Journal every decision.** Setiap keputusan buy/sell/hold/pass wajib punya Decision Journal.
3. **Thesis before trade.** Tidak boleh eksekusi trade tanpa thesis tertulis.
4. **Weekly review.** Setiap Sabtu / Minggu evaluasi minggu berjalan.
5. **Cek emotional state.** Sebelum trade, isi checklist di Decision Journal.
