# 📥 Cara Pakai Inbox

> Inbox = tempat capture cepat sebelum diproses ke folder lain.
> Jangan simpan analysis panjang di sini.

---

## Struktur

```
00_Inbox/
├── Berita & Sinyal/     → link/potongan berita, tweet, sinyal market
├── Ide Riset/           → emiten mana yang menarik untuk diteliti
└── Quick Notes/         → pemikiran cepat yang belum jadi note lengkap
```

---

## Workflow

1. **Capture** apa pun di sini (nama emiten, headline, screenshot chart, ide).
2. **Weekly review**, pindahkan:
   - Ide riset → `01_Projects/Riset [TICKER] [Quarter].md`
   - Berita → arsip / link di daily note
   - Konsep → `03_Resources/Konsep/`
3. **Kosongkan Inbox** setiap minggu (target < 5 item).

---

## Aturan

- Isi cepat, jangan overthink judul
- Tambahkan tag `#inbox` supaya mudah difilter
- Kalau > 2 minggu belum diproses, delete atau move
